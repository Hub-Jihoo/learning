# Python 增删查改速查表

> 覆盖 list、dict、set、str、tuple 五种常用数据结构，以及通用内置函数。
> 标注了版本要求的语法需要 Python 3.9+。

Python 里“增删查改”没有一套统一函数，**要看你在操作什么类型**：列表、字典、集合、字符串，方法都不一样。

我先按最常用的几种数据结构给你整理。

---

## 一、列表 list

列表是可变对象，很多方法会**原地修改**，返回值通常是 `None`。

### 增

| 方法 | 作用 |
|---|---|
| `append(x)` | 末尾添加一个元素 |
| `insert(i, x)` | 在索引 `i` 前插入 `x` |
| `extend(iterable)` | 把另一个可迭代对象里的元素逐个加到末尾 |
| `+` | 拼接两个列表，返回新列表 |

```python
a = [1, 2, 3]
a.append(4)        # [1, 2, 3, 4]
a.insert(1, 99)    # [1, 99, 2, 3, 4]
a.extend([5, 6])   # [1, 99, 2, 3, 4, 5, 6]
```

### 删

| 方法 | 作用 |
|---|---|
| `pop()` | 删除并返回最后一个元素 |
| `pop(i)` | 删除并返回索引 `i` 的元素 |
| `remove(x)` | 删除第一个值为 `x` 的元素 |
| `clear()` | 清空列表 |
| `del a[i]` | 删除索引 `i` 的元素 |
| `del a[i:j]` | 删除切片范围 |

```python
a = [1, 2, 3, 2]
a.remove(2)   # [1, 3, 2]
x = a.pop()   # x=2, a=[1, 3]
a.clear()     # []
```

### 查

| 方法 | 作用 |
|---|---|
| `a[i]` | 按索引取元素 |
| `a[i:j]` | 切片 |
| `index(x)` | 查找 `x` 第一次出现的索引 |
| `count(x)` | 统计 `x` 出现次数 |
| `x in a` | 判断是否存在 |
| `len(a)` | 列表长度 |

```python
a = [10, 20, 30, 20]
print(a[0])        # 10
print(a.index(20)) # 1
print(a.count(20)) # 2
print(20 in a)     # True
```

### 改

| 方法 | 作用 |
|---|---|
| `a[i] = x` | 修改索引 `i` 的元素 |
| `a[i:j] = ...` | 切片赋值，可改变长度 |
| `sort()` | 原地排序 |
| `reverse()` | 原地反转 |
| `sorted(a)` | 返回排序后的新列表，不改原列表 |

```python
a = [3, 1, 2]
a[0] = 99      # [99, 1, 2]
a.sort()       # [1, 2, 99]
a.reverse()    # [99, 2, 1]
```

## 二、字典 dict

字典是“键值对”结构，增删查改主要围绕 **key** 进行。

### 增 / 改

| 方法 | 作用 |
|---|---|
| `d[key] = value` | 有则改，无则增 |
| `setdefault(key, default)` | 有则返回旧值，无则插入默认值 |
| `update(other)` | 批量更新 |

```python
d = {"name": "Tom"}
d["age"] = 18          # 增
d["age"] = 20          # 改
d.setdefault("city", "北京")
d.update({"score": 90})
```

### 删

| 方法 | 作用 |
|---|---|
| `pop(key)` | 删除并返回键对应的值 |
| `popitem()` | 删除并返回最后一个键值对，3.7+ |
| `del d[key]` | 删除指定键 |
| `clear()` | 清空 |

```python
d = {"a": 1, "b": 2}
x = d.pop("a")   # x=1, d={"b": 2}
d.popitem()      # 删除 ("b", 2)
```

### 查

| 方法 | 作用 |
|---|---|
| `d[key]` | 取值，键不存在会报错 |
| `get(key, default)` | 取值，不存在返回默认值 |
| `keys()` | 所有键 |
| `values()` | 所有值 |
| `items()` | 所有键值对 |
| `key in d` | 判断键是否存在 |
| `len(d)` | 键值对数量 |

```python
d = {"name": "Tom", "age": 18}
print(d["name"])          # Tom
print(d.get("score", 0))  # 0
print("age" in d)         # True
```

## 三、集合 set

集合无序、不重复。

### 增

| 方法 | 作用 |
|---|---|
| `add(x)` | 添加一个元素 |
| `update(iterable)` | 批量添加 |

### 删

| 方法 | 作用 |
|---|---|
| `remove(x)` | 删除 `x`，不存在报错 |
| `discard(x)` | 删除 `x`，不存在不报错 |
| `pop()` | 删除并返回任意一个元素 |
| `clear()` | 清空 |

### 查

| 方法 | 作用 |
|---|---|
| `x in s` | 判断是否存在 |
| `len(s)` | 元素个数 |
| `issubset()` | 是否为子集 |
| `issuperset()` | 是否为超集 |
| `isdisjoint()` | 是否无交集 |

### 改 / 集合运算

| 方法 | 作用 |
|---|---|
| `union()` / `|` | 并集 |
| `intersection()` / `&` | 交集 |
| `difference()` / `-` | 差集 |
| `symmetric_difference()` / `^` | 对称差集 |

---

## 四、字符串 str

字符串是**不可变**的。  
所以字符串的“增删改”通常都是**返回新字符串**，不会改原字符串。

### 增

| 方法 | 作用 |
|---|---|
| `+` | 拼接 |
| `join()` | 用分隔符连接多个字符串 |
| `f"{x}"` | 格式化插入 |

### 删

| 方法 | 作用 |
|---|---|
| `replace(old, new)` | 替换，可当删除用 |
| `removeprefix(prefix)` | 删除开头前缀，3.9+ |
| `removesuffix(suffix)` | 删除结尾后缀，3.9+ |
| `strip()` | 删除两端空白或指定字符 |
| `lstrip()` / `rstrip()` | 删除左端 / 右端 |

### 查

| 方法 | 作用 |
|---|---|
| `find(x)` | 找子串，找不到返回 `-1` |
| `index(x)` | 找子串，找不到报错 |
| `count(x)` | 统计出现次数 |
| `startswith(x)` | 是否以某前缀开头 |
| `endswith(x)` | 是否以某后缀结尾 |
| `x in s` | 是否包含 |
| `len(s)` | 长度 |

### 改

| 方法 | 作用 |
|---|---|
| `upper()` | 转大写 |
| `lower()` | 转小写 |
| `capitalize()` | 首字母大写 |
| `title()` | 每个单词首字母大写 |
| `replace()` | 替换 |
| `split()` | 分割成列表 |
| `join()` | 列表拼成字符串 |

---

## 五、元组 tuple

元组不可变，所以**不能增、不能删、不能改**。

只能查：

| 方法 | 作用 |
|---|---|
| `t[i]` | 按索引取 |
| `t[i:j]` | 切片 |
| `count(x)` | 统计 |
| `index(x)` | 查找索引 |
| `x in t` | 是否存在 |
| `len(t)` | 长度 |

---

## 六、通用函数

这些不专属于某个类型：

| 函数 | 作用 |
|---|---|
| `len(x)` | 长度 |
| `x in y` | 成员判断 |
| `id(x)` | 对象地址标识 |
| `type(x)` | 类型 |
| `sorted(x)` | 返回排序后的新列表 |
| `reversed(x)` | 返回反向迭代器 |
| `enumerate(x)` | 同时拿到索引和值 |
| `zip(a, b)` | 并行打包 |
| `sum(x)` | 求和 |
| `min(x)` / `max(x)` | 最小 / 最大 |

---

## 七、最重要的一句话

> **列表、字典、集合很多方法是原地修改，返回 `None`。**  
> **字符串不可变，所有“修改”都返回新字符串。**  
> **字典按 key 操作，集合无序，元组不可变。**
