# python-basics · Python 基础练习

本目录收录 Python 课程实验中的代码与学习笔记。

## 文件说明

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `实验1.py` | 代码 | 输入学号、姓名、性别、籍贯，使用 f-string 格式化输出 |
| `notes/Python-增删查改速查.md` | 笔记 | list / dict / set / str / tuple 的增删查改与通用内置函数 |
| `practice/a=100.txt` | 代码片段 | 变量赋值与 `print` 的最小示例 |

## 运行方式

```bash
# 在仓库根目录执行
python python-basics/实验1.py
```

`实验1.py` 需要交互式输入，运行后按提示依次填写即可。示例：

```text
请输入学号：202500000000000
请输入姓名：张三
请输入性别：男
请输入籍贯：广东
学号：202500000000000，姓名：张三，性别：男，籍贯：广东
```

## 关于实验报告

课程实验 1–5 的 Word 报告保存在本地，**未上传到本仓库**：

- 旧版 `.doc` 文件内部直接包含学号与姓名，二进制格式难以可靠脱敏；
- `.docx` 文件名同样带有个人信息，且文档内可能含截图。

如果确实需要公开，建议先另存为 PDF、删除封面个人信息并打码截图，再上传到单独的私有仓库或脱敏后的目录。

## 学习建议

1. 先运行代码，观察输出；
2. 对照速查笔记，把示例改成自己的数据；
3. 每完成一个小练习就提交一次，提交信息写清楚做了什么。
